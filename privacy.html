Privacy policy

Your Google authorization is used for the publishing actions you choose.

Effective and last updated: 21 October 2026 · 中文对照

1. Who operates MIX

MIX YouTube is a private, locally operated video workflow maintained by Zhang Longsheng (张隆生) for personal use and a limited, known team. Contact: hubinglie@gmail.com. This policy covers the local application, its use of YouTube API Services, and this public information website.

2. Information accessed and stored

  • Authorization: Google OAuth client configuration and refresh credentials needed to renew access. Google handles sign-in; MIX does not collect your Google password.
  • Channel identity: the connected channel's ID and display name, used to verify the publishing destination.
  • Publishing information: the video selected by the owner; its title, description, hashtags, backend tags, audience and visibility settings; and YouTube video IDs, processing status and metadata returned to verify the result.
  • Local workflow records: video and draft versions, file hashes, human confirmations, upload session references, publishing receipts and relevant errors.
  • Copy-generation inputs: story material, subtitles and feedback supplied in the local workflow to prepare bilingual publishing copy.

The requested Google permission is youtube.force-ssl. Google's consent screen describes a broader permission group, including changes to videos, ratings, comments and captions. MIX currently implements channel verification, approved video uploads, result checks and visibility changes; it does not implement account management or remote deletion.

3. Purpose and human control

MIX uses this information to prepare and review publishing copy, confirm the correct channel and video version, perform explicitly approved uploads, check the result and perform a separately approved public release. The initial upload is private. Connecting an account is not approval to upload or publish.

A fixed channel ID identifies the publishing destination. Display-name changes do not redirect publishing. Data is not used for advertising, sold, or used by MIX to train general-purpose AI models. MIX's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

4. Processing and sharing

Chosen videos and approved metadata are sent to Google/YouTube through the official API. OAuth credentials are sent only to Google's authorization and API endpoints as required for this connection. Authorized local operators may access workflow records to operate or troubleshoot the tool.

If the owner uses AI-assisted copy generation, the supplied story, subtitles and feedback are sent through the configured model service. The publishing connection does not send Google authorization credentials or YouTube API responses to the copy-generation model. Do not include credentials in story material or feedback.

This public site does not receive videos, Google tokens or local publishing records. It is hosted on GitHub Pages. GitHub processes normal hosting request information, including visitor IP addresses, under the GitHub Privacy Statement. The site contains no analytics scripts, advertising, tracking pixels, embedded videos or account forms. External links are governed by their destination's policies.

5. Storage and security

Publishing credentials and workflow records are stored on the operator's local machine. Credential files are kept in a restricted local directory, separate from the public website and source repository. Connections to Google use HTTPS. Local access controls are used to limit access; no guarantee of absolute security is made.

The local application stores working state and may store review drafts in the browser on that machine. These local records are separate from this public website, which does not set its own cookies or browser storage.

6. Retention, disconnection and deletion

Credentials are retained while the owner keeps the connection enabled. Publishing records are retained locally as needed to verify actions, avoid duplicate uploads and support the active workflow. YouTube API data must be refreshed or removed within the applicable YouTube retention periods, including the 30-day rule where required; the operator is responsible for this review and cleanup. MIX does not provide a public cloud archive.

You can revoke MIX's Google access at any time through Google Account permissions. Revocation prevents renewed API access but does not itself erase local records or delete videos already on YouTube.

To disconnect locally or request deletion of stored authorization and YouTube API data, contact hubinglie@gmail.com. The operator will verify the request, remove the relevant local credentials and API data, and address any operator-controlled copies as soon as possible and within seven calendar days after a verified deletion request or known revocation. This cleanup is handled by the operator; it is not an automatic remote wipe. Local source videos and independently created editing files are handled according to the owner's instructions. Deleting local MIX data does not delete data held by YouTube; manage uploaded videos separately in YouTube Studio.

7. Google policies, changes and questions

MIX uses YouTube API Services. Google's processing is described in the Google Privacy Policy. Use of YouTube is subject to the YouTube Terms of Service.

This policy will be updated when the tool's practices change. Material changes to how authorized data is used require renewed agreement before that new use. Questions, privacy complaints and deletion requests can be sent to the support address above.

隐私政策

生效及更新日期：2026 年 10 月 21 日。MIX YouTube 由张隆生维护，供本人及少量熟悉的团队成员使用。联系邮箱：hubinglie@gmail.com。本政策涵盖本地程序、YouTube API 调用及此公开说明网站。

访问什么数据、用来做什么

本地保存 Google OAuth 客户端配置和持续授权凭据，以便更新访问权限；Google 处理登录，MIX 不收集 Google 密码。程序读取频道 ID 和名称来核对发布目标，处理用户选定的视频、标题、简介、话题标签、后台标签、受众与可见性设置，并读取 YouTube 返回的视频编号、处理状态和文案以核对结果。还会保留本地版本、文件摘要、人工确认、上传会话引用、回执和相关错误。生成发布文案所需的剧情、字幕和反馈由用户在本地流程中提供。

Google 的 youtube.force-ssl 权限组包含视频、评分、评论和字幕等较广的权限；MIX 当前只实现频道核对、经确认的视频上传、结果核验和可见性更改，没有账号管理或远程删除功能。先经用户确认上传为私密，再经用户单独确认才公开；连接账号本身不算上传或公开许可。固定频道 ID 用于识别目标，改名不改变绑定。MIX 不出售这些数据，不将其用于广告或通用 AI 模型训练，并遵守 Google API 用户数据政策及其中的 Limited Use 要求。

传给谁、存在哪里

选定的视频及获批文案通过官方接口发送至 Google/YouTube；授权凭据仅按连接所需发送到 Google 的授权和 API 接口。获准操作本机的人员可为运行与排障查看本地记录。若使用 AI 文案生成，用户提供的剧情、字幕和反馈会经配置的模型服务处理；发布连接不会把 Google 授权凭据或 YouTube API 回应发送给文案模型。请勿在剧情资料或反馈中粘贴凭据。

凭据和发布记录存放在操作者本机，凭据目录限制访问，并与公开网站、代码仓库分开；连接 Google 使用 HTTPS。本地工作界面可能在本机浏览器保存审阅草稿。此公开网站不接收视频、授权或发布记录，不设置自己的 Cookie 或本地存储，不加载统计、广告、追踪像素、嵌入视频或登录表单。GitHub Pages 托管方会按其隐私政策记录 IP 地址等常规访问资料。外部链接按目标网站政策处理。

保留、撤销与删除

授权保持启用时保留凭据；本地发布回执按核对操作、避免重复上传及当前流程的需要保留。操作者须按 YouTube 适用期限复核、更新或移除 API 数据，包括适用时的 30 天规则。MIX 不提供公开云端归档，也不承诺绝对安全。

你可在 Google 账号权限设置撤销 MIX。撤销会阻止继续更新访问权限，但不会自动清除本地记录或已上传视频。请发邮件到上述地址申请断开本地连接或删除授权及 YouTube API 数据；操作者核实后将尽快处理，并在核实删除请求或获悉撤销授权后的七个自然日内清理相关本地数据及由其控制的副本。这是人工清理，并非自动远程擦除。原片和独立制作的剪辑文件按所有者指示处理。清除 MIX 本地数据不会删除 YouTube 数据；平台视频需在 YouTube Studio 中另行管理。

MIX 使用 YouTube API Services，并受相关 YouTube 服务条款及 Google 隐私政策约束。数据用途发生实质变化前，会更新本政策并重新征得同意。隐私问题、投诉和删除请求可发往联系邮箱。
